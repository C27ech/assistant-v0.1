# style/ —— 风格系统数据目录

这个目录决定「助手说话像谁」。三个文件：

| 文件 | 必需 | 作用 |
|------|------|------|
| `style_guide.md` | 建议有 | **风格说明书**：口癖、句式、语气分寸、禁忌。整段注入系统提示词（常驻） |
| `corpus.txt` | 建议有 | **检索语料**：每行一句，用来每轮动态召回最相关的几句当范例 |
| `corpus_distill.txt` | 可选 | **蒸馏语料**：给 `build_style_guide.py` 用，可以比检索语料更大（中英混排也行） |

> 仓库里这三个文件都是**通用示例**（我自己写的），没有任何第三方作品内容。
> 你要模仿谁的语气，请自备**你有权使用的**文本。

## 自己造一份

```bat
cd assistant

:: 1) 把语料放进 style\corpus.txt —— 每行一句，空行与 # 开头的行会被忽略
::    （想清洗一下就先跑：python scripts\clean_corpus.py）

:: 2) 生成风格说明书（分批归纳 + 合并，语料多的话要几分钟）
python scripts\build_style_guide.py

:: 3) 重启助手，观察效果
```

## 语料格式

- **每行一句**，越干净越好（去掉旁白、他人台词、时间轴、角色名前缀）
- 单句太短（< 12 字）的会在检索时被跳过——它们展示不出句式
- 量大不一定更好：**换个来源**（不同场合/情绪）通常比同一来源堆量有效
- 想控制不同来源的占比，可以在导入阶段按权重交错（见脚本里的参数）

## 调参

| 想改什么 | 改哪里 |
|----------|--------|
| 风格浓/淡 | 直接编辑 `style_guide.md` |
| 每轮注入几句范例 | `config/style.py` 的 `build_style_block(query, k=...)` 调用处（或决策 AI 的 `style_examples` 参数） |
| 完全不要风格 | 删掉 `style_guide.md`（会退回兜底），或把系统提示词里的 `{STYLE}` 占位符去掉 |

## 兜底行为

- `style_guide.md` 不存在 → 使用 `config/style.py` 里的 `_FALLBACK_GUIDE`（一段极简中性风格）
- `corpus.txt` 不存在/为空 → 只注入说明书，不做例句检索（功能正常，只是少了"灵气"）

# 游戏内 HELP 按键表（KEYBOARD & MOUSE 第 1/2 页）—— 原始记录

> 来源：STEINS;GATE（Steam 中文版）标题画面 → HELP 页面截图 `sg_bridge/out/sg_05_help2.png`
> （2026-09-10 会话中成功读图后逐项记录；放大件：`zoom_keys1/2/3.jpg`、`zoom_hint.jpg`）
> 用途：新会话可据此直接复用，无需再读图。

## 键盘（自上而下、自左而右）

| 键 | 功能 |
|---|---|
| ESC | 游戏结束（退出，会弹确认） |
| F1 | 帮助 |
| F2 | 备份日志 |
| F3 | 自动模式 |
| F4 | TIPS |
| F5 | 快速保存 |
| F6 | 载入 |
| F7 | 快速载入 |
| F8 | 保存 |
| F9 | 配置 |
| F10 | 回到标题画面 |
| F11 | 全屏切换 |
| F12 | 截图 |
| **1** | **系统菜单**（图中明确：标签「系统菜单」的引线指向数字键 1） |
| BACKSPACE | 返回 |
| ENTER | 确定 |
| INSERT | 备份日志（第二键） |
| DELETE | 自动模式（第二键） |
| ↑↓←→ | 项目选择 / TIPS 正文滚动 |
| **SHIFT** | **隐藏文字**（引线明确指向 SHIFT） |
| **CTRL** | **强行快进**（引线明确指向 CTRL） |
| **Z** | 手机触发器（用户实测确认：Z 打开手机） |
| **X** | 收起手机（用户实测确认） |
| C / E | 图中该区域还有被高亮的键（C、E）；其中 **C 实测能再次打开手机**（待确认是否为手机触发器第二键），**E 在 CONFIG 里是「切换页面」** |

## 鼠标

| 操作 | 功能 |
|---|---|
| 左键 | 确定 |
| 右键 | 返回 / 系统菜单（仅游戏中） |
| 滚轮 | 列表与正文的滚动、备份日志 |

## 状态
* 以上已写入 `sg_bridge/core/games.py` 的 `MAGES_DEFAULT`（`confidence: verified/help`）。
* 手机相关：`phone`=Z、`phone_alt`=C、`phone_close`=X；`back`=BACKSPACE。
* **待新会话验证**：`phone_alt`(C) 究竟是不是手机触发器第二键（需在游戏里做 Z/X/C 的往返指纹测试）。
